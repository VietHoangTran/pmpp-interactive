`s112_kogge_stone.cu` differs from the page in two ways, both said in the lessons: the
two kernels are renamed (the book calls both `scan_kernel`), and line 14 of Fig. 11.3,
printed `__ syncthreads();`, is written so that it compiles.

The three "as printed" files keep the book's text, including what HIP and Metal reject (the
32-bit mask literal, `__shared__` inside a `__device__` function) and what makes Figs. 11.12
and 11.13 wrong for a partial last segment (they never read `N`): the lessons show them as
the book's code and point at those lines. The corrected versions are labs 11.1 and 11.2.
